# Machine Learning con Python

## Objetivo del proyecto

Desarrollar un modelo de Machine Learning con Python, aplicando técnicas de análisis, procesamiento de datos y entrenamiento de modelos para realizar predicciones y evaluar su rendimiento.

## Tecnologías utilizadas

- **Python:** lenguaje de programación principal.
- **Pandas:** manipulación y procesamiento de datos.
- **NumPy:** operaciones numéricas y matemáticas.
- **Matplotlib y Seaborn:** visualización de datos.
- **Scikit-learn:** entrenamiento y evaluación de modelos.
- **Jupyter Notebook:** análisis y experimentación.
- **Git y GitHub:** control de versiones.

## Alcance inicial

- Obtención y exploración del conjunto de datos (dataset).
- Limpieza y preprocesamiento de datos.
- Análisis exploratorio de datos (EDA).
- Selección del algoritmo de Machine Learning.
- Entrenamiento y validación del modelo.
- Evaluación de resultados mediante métricas de rendimiento.
- Optimización del modelo.
